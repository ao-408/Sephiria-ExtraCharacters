# Sephiria Costume AddOn

セフィリア用の新しいコスチュームをいくつか追加するMODです。
**今後のアップデートでさらに多くのコスチュームが追加される予定です**。

## 特徴

- セフィリアに新規コスチュームを追加
- 追加されるコスチュームは、それぞれ独自の新しい効果やアーティファクトを所持しています
