# Sephiria Costume AddOn

セフィリアに新しいコスチュームを追加するAddOnです。
既存キャラクターの見た目のバリエーションを増やすことが目的で、**通常プレイのゲームバランスやステータスには一切影響しません**。

## 特徴

- セフィリアに新規コスチュームを追加
- 追加されるコスチュームは見た目のみの変更で、能力値・ステータス・ゲームバランスには影響しません
- 既存のセーブデータやプレイに支障なく導入できます
